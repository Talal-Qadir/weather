# Django API

See the root README for full architecture, setup, provider and deployment notes. Quick start: copy `.env.example` to `.env`, configure `OPENROUTESERVICE_API_KEY` for HeiGIT geocoding/routing and optionally `HERE_ROUTING_API_KEY` for secondary global truck routing, install `requirements.txt`, then run `python manage.py check`, `python manage.py test`, and `python manage.py runserver`.
